Build a complete Android money manager application called PocketLedger using Kotlin, Jetpack Compose, MVVM architecture, Room Database, Hilt dependency injection, and Kotlin Coroutines. The app must include every feature listed below.

Authentication & Cloud

Google Sign-In via Firebase Authentication on the splash/login screen. After login show the user's name, email, and profile photo. Implement Google Drive API v3 backup: auto-sync every 24 hours and on-demand manual sync. Store backup as encrypted JSON in the user's Drive app folder. Show sync status and last backup time in Settings.

Multiple Accounts

Support unlimited accounts: Bank Account, Cash Wallet, Credit Card, Mobile Wallet, Investment, Savings. Each account has a name, icon, color, currency, and starting balance. Show account balance cards on Dashboard with horizontal scroll. Include a dedicated Accounts screen with net worth summary. Support inter-account transfers with a from/to selector and optional notes.

Transactions

Full transaction CRUD: Expense, Income, Transfer, Bank Transfer. Fields: amount, category, account, date, time, note, attachment (photo/receipt). Implement recurring transactions (daily, weekly, monthly, custom). Support split transactions across categories. Show transactions grouped by date with running balance. Include search and advanced filter (date range, account, category, amount range).

Categories

Pre-built categories with custom icons: Food & Dining, Transport, Shopping, Health, Utilities, Entertainment, Education, Travel, Salary, Freelance, Investment, Rent, Loan, Insurance, Gifts, Subscriptions, Household, Personal Care, Other. Allow user to create, edit, delete, and reorder custom categories. Each category has a color and icon from Material Icons or custom SVG.

Loans Manager

Full Loan/Debt tracker: lent (you gave money) and borrowed (you owe money). Fields: person name, amount, interest rate (optional), due date, partial payment history, notes. Show progress bar for repayment. Send reminder notifications before due dates (1 week, 3 days, 1 day). Summary card showing total lent vs owed.

Analytics & Reports

Dashboard with monthly income/expense/savings summary cards. Bar chart for 6-month spending trend. Donut/pie chart for category breakdown. Line chart for net worth over time. Budget progress bars per category. Monthly/weekly/custom date range selector. Export reports as CSV, PDF, Excel (.xlsx).

Budgets & Goals

Set monthly budgets per category. Visual budget gauge showing used vs remaining. Alert when 80% and 100% reached. Savings goals with target amount, deadline, and contribution tracking. Progress ring animation for goals.

Bottom Navigation

5-tab bottom nav: Home, Analytics, [+FAB in center], Loans, Settings. The center button is a large floating action button elevated above the nav bar. Tapping it opens an animated bottom sheet with options: Add Expense, Add Income, Transfer, Bank Transfer, Add Loan, Scan Receipt.

Notifications & Sounds

Full notification system using WorkManager + NotificationCompat: bill reminders, budget alerts (80%/100%), loan due reminders, recurring transaction alerts, Google Drive sync status, and in-app update available notification. Play a distinct sound on each successful transaction (cash register sound). All notification categories toggleable in Settings. Use notification channels for Android 8+.

In-App Updates

Integrate Google Play In-App Update API (Flexible update). Check for updates on app launch. Show a non-intrusive banner on Dashboard when update is available. Show update notification in notification panel. Allow user to dismiss and update later.

Themes

Full Material Design 3 Dynamic Color support. Light and Dark themes. Theme selector in Settings: System default, Light, Dark. Smooth animated theme transition. Custom accent color picker (6 preset colors + custom).

Security

Optional Biometric lock (fingerprint/face) on app open using BiometricPrompt. PIN fallback. Auto-lock after configurable timeout (1 min, 5 min, 15 min). Encrypted Room database using SQLCipher.

Additional Features

Scan Receipt using ML Kit text recognition to auto-fill transaction amount and merchant. Currency converter with live exchange rates. CSV/Excel import for bulk transaction upload. Widget showing balance and quick-add button. Multi-currency support per account. Dark/Light auto-schedule by time of day.

Tech Stack Requirements

Use: Kotlin 1.9+, Compose BOM latest, Room 2.6+, Hilt 2.50+, Navigation Compose, DataStore Preferences, WorkManager, Coil for images, MPAndroidChart or Compose Charts, Firebase Auth, Google Drive API, Play In-App Update, BiometricPrompt, ML Kit Text Recognition, Retrofit + OkHttp for exchange rates, Accompanist libraries. Min SDK 26, Target SDK 34. Follow clean architecture: data / domain / presentation layers. Write unit tests for ViewModels and use-cases with JUnit5 + MockK. Write UI tests with Compose Testing.

Required GitHub Secrets
KEYSTORE_BASE64
Base64-encoded release keystore .jks file. Run: base64 keystore.jks | pbcopy
KEYSTORE_PASSWORD
Password used when creating the keystore file with keytool.
KEY_ALIAS + KEY_PASSWORD
The alias name and its password used in your keystore.
GOOGLE_SERVICES_JSON
Base64-encoded google-services.json from Firebase Console.
PLAY_SERVICE_ACCOUNT_JSON
Google Play API service account JSON for automated store uploads.
Setup Steps
  • 1
    Firebase Project — Create project at console.firebase.google.com. Enable Google Sign-In under Authentication. Download google-services.json into /app/.
  • 2
    Google Drive API — In Firebase project, enable Drive API in Google Cloud Console. Add OAuth scope drive.appdata for per-user backup storage.
  • 3
    Generate Keystore — Run: keytool -genkey -v -keystore keystore.jks -alias pocketledger -keyalg RSA -keysize 2048 -validity 10000. Keep it safe — you cannot change it after publishing.
  • 4
    Add GitHub Secrets — Go to Repo → Settings → Secrets. Add all 6 secrets listed above. Never commit these files to the repo.
  • 5
    Play Store Setup — Create app in Google Play Console. Create a Service Account with Release Manager permissions. Download JSON key. Add as PLAY_SERVICE_ACCOUNT_JSON secret.
  • 6
    First Release — Push tag: git tag v1.0.0 && git push origin v1.0.0. GitHub Actions will build, sign, and upload to Play Store internal track automatically.
  • 7
    In-App Updates — Integrate play-core library in build.gradle. Use AppUpdateManager to check for updates on app launch. Show flexible update flow (downloads in background).
  • 8
    App Icon — Use Android Studio's Image Asset Studio. Design a coin/wallet icon. Export all mipmap densities (mdpi to xxxhdpi) including adaptive icon layers for Android 8+.
